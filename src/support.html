Support

Host the src folder on HTTPS, set that host with node scripts/set-host.mjs https://your-host, then sideload manifest.xml.

Current Microsoft sideload path (not the new Store): open https://aka.ms/olksideload, choose My add-ins, then Custom Addins → Add a custom add-in → Add from File.

Org-wide: Microsoft 365 admin centre → Settings → Integrated apps → Upload custom apps. Event-based OnMessageSend needs admin deployment for production use.
